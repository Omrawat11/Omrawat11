# Contributing to Om's Open-Source Repositories & Profile

First off, thank you for considering contributing! Community collaboration and knowledge-sharing are at the heart of open source.

## How Can You Contribute?

1. **Reporting Bugs & Issues**:
   - Check existing issues before opening a new one.
   - Provide a clear title, description, and reproducible steps or logs.

2. **Suggesting Enhancements**:
   - Open an issue explaining the feature, motivation, and practical machine learning or software utility.

3. **Submitting Pull Requests**:
   - Fork the repository and create your branch from `main`:
     ```bash
     git checkout -b feature/my-new-feature
     ```
   - Follow clean code practices (PEP 8 for Python).
   - Write clear, conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`).
   - Submit your pull request against the `main` branch with a concise summary of changes.

## Code of Conduct

Be respectful, constructive, and inclusive to all contributors and learners.
